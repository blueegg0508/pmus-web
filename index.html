홈 화면에 추가해 주세요

앱처럼 아이콘으로 열리고, 한 번 연 뒤로는 인터넷 없이도 씁니다.

  1. 1. 사파리 아래쪽 공유 버튼을 누릅니다.
  2. 2. 목록을 내려 홈 화면에 추가를 누릅니다.
  3. 3. 오른쪽 위 추가를 누르면 홈 화면에 PMUS 아이콘이 생깁니다.
  4. 4. 앞으로는 그 아이콘으로 여세요. 라이선스도 거기서 등록합니다.

사파리가 아닌 다른 앱(카카오톡 등) 안에서 열었다면, 오른쪽 위 메뉴에서 사파리로 열기를 먼저 눌러 주세요.
